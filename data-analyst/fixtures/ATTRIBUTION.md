# Dataset attribution

Sample derived from **Online Retail** (UCI Machine Learning Repository).

- Chen, D. (2015). *Online Retail*. UCI Machine Learning Repository.
  https://doi.org/10.24432/C5BW33
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Source: https://archive.ics.uci.edu/dataset/352/online+retail

`online_retail_sample.csv` is a ~12k-row demo slice (Jan–Mar 2011; UK, France,
Germany, EIRE, Netherlands; non-null `CustomerID`; `random_state=42`). The same
slice is regenerated into `/workspace/data/online_retail.csv` by
`sandbox/setup.sh` at bake time.
